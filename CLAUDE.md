# Advisory

Software-supply-chain security platform — a .NET 10 API + React console + Rust/`.said` tooling. A
package/CVE catalog, a security gate (allow/block), a Nexus firewall, and a self-evolution loop.

## Agent skills

### Issue tracker

Issues are tracked as GitHub issues in `Qonsult1001/advisory` (via the `gh` CLI); external PRs are
**not** a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`,
`wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
